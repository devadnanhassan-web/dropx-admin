# Changelog

All notable changes to DropX Admin are documented in this file.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org).

## [1.0.1] - 2026-10-26

### Changed

- License now permits free redistribution, including on template marketplaces, as long as the "Designed & developed by DataDropX" credit stays and DataDropX is named as the original author. Reselling the template as a paid product is not allowed.
- README gains a Download section.

## [1.0.0] - 2026-10-26

First public release as a free template under the DropX Admin License.

### Added

- 8 dashboards: Default, Analytics, CRM, E-commerce, LMS, Project Management, SaaS and Support Desk
- 9 apps: E-commerce, Email, Events, E-learning, Social, Support Desk, Calendar, Chat and Kanban
- 18 authentication screens in Simple, Card and Split styles
- User profile, settings, pricing, FAQ, error, landing and misc pages
- 30+ UI component demos, form and table modules, charts, maps, icon galleries and utilities
- Collapsible sidebar with mobile and tablet drawer, header search shortcut (`Ctrl` / `Cmd` + `K`) and user menu
- Light, dark and system themes
- `Select`, `Textarea` and `Checkbox` form primitives sharing one field style
- Theme-aware chart palette and shared chart tooltip and axis styles
- Route loading skeleton for the admin area
- DataDropX branding: logo, favicon, Apple icon, Open Graph image and footer credit
- Per-page titles, Open Graph and Twitter metadata, `robots.txt` and `sitemap.xml`

### Accessibility

- Visible focus ring on all interactive elements
- Labelled form controls and icon buttons
- Reduced-motion support
- 11px minimum text size and contrast-checked muted text
