# Installation

This template runs on Next.js 16 (App Router) with Turbopack. Requirements and
setup steps are below.

## Requirements

- **Node.js** `20.x` or newer (see `.nvmrc`). Important: **Node 20+ is required**
  for Next.js 16.
- **yarn** `1.22+` (recommended). The lockfile is `yarn.lock` and this project is
  managed with Yarn. Avoid mixing package locks (`package-lock.json`, `pnpm-lock.yaml`).

## 1. Install dependencies

```bash
yarn install
```

If you must use a different package manager, delete `yarn.lock` first, then install —
but re-generating the lockfile may resolve slightly newer versions.

## 2. Start development server

```bash
yarn dev
```

Open http://localhost:3000 — the root route redirects to `/dashboard`.

## 3. Production build

```bash
yarn build    # static export-ready production build (149 routes)
yarn start    # run the production server locally
```

## Available scripts

| Script         | Description                                    |
| -------------- | ---------------------------------------------- |
| `yarn dev`     | Start dev server (Turbopack)                   |
| `yarn build`   | Create an optimized production build           |
| `yarn start`   | Run the production build locally               |
| `yarn lint`    | ESLint check                                   |
| `yarn typecheck`| TypeScript type checking (`tsc --noEmit`)     |
| `yarn format`  | Format all files with Prettier                 |

## Troubleshooting

- **Port already in use** — Next.js auto-selects the next free port; look at the
  terminal output for the URL.
- **TypeScript errors after a fresh clone** — run `yarn install` (the `.next/types`
  folder is generated by the first `yarn build`).
- **ESLint output a circular-structure error** — ensure `eslint@9` and
  `eslint-config-next@16` are installed per `package.json` (flat config is used
  directly, no `.eslintrc`).
